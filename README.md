# TM- 팀 프로젝트

팀원들이 코드를 공유하고 공동 작업하는 GitHub 저장소입니다.

## 폴더 구조

- `code/`: Python 코드와 Jupyter Notebook 등 소스 코드
- `data/`: 공유 가능한 데이터 파일 (개인정보·비밀번호·API 키 제외)
- `results/`: 분석 결과, 그래프 및 산출물

## 함께 작업하는 방법

1. 저장소를 Clone하거나 GitHub에서 파일을 내려받습니다.
2. 작업 전 `git pull`로 최신 변경 사항을 받습니다.
3. 가급적 각자 별도 브랜치에서 작업하고 Pull Request로 합칩니다.
4. 변경 사항을 Commit한 후 Push합니다.

> 이 저장소는 **Public**입니다. 비밀번호, 토큰, 개인정보, 비공개 데이터는 올리지 마세요.
